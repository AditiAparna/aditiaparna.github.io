# aditiaparna.github.io

Personal portfolio site for Aditi Aparna — Senior Frontend Developer.

**Live at:** [aditiaparna.github.io](https://aditiaparna.github.io/)

## Tech Stack

- Vanilla HTML, CSS, JavaScript (zero build tools — ships directly to GitHub Pages)
- Instrument Serif + DM Sans + JetBrains Mono from Google Fonts
- CSS custom properties, `clamp()`, and container queries for responsive design
- Intersection Observer API for scroll-triggered reveal animations
- Smooth cursor-following glow effect (desktop)
- Animated stat counters, marquee ticker, and 3D tilt on timeline cards
